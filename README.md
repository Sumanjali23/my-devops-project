## 📌 Overview

This project demonstrates a production-style **CI/CD pipeline** integrating Docker containerisation and GitHub Actions automation. It includes a multi-language stack (TypeScript frontend + Python backend), lab exercises, and automated workflows for testing and deployment.

---

## ✨ Features

- 🔄 Automated CI/CD via GitHub Actions workflows
- 🐳 Docker and Docker Compose containerisation
- 🖥️ TypeScript + Python multi-service architecture
- 🔧 Shell scripting for automation
- 📚 Hands-on lab exercises (`code-lab1`)

---

## 🚀 Getting Started

### Prerequisites
- Docker & Docker Compose
- Node.js / Python 3.8+

### Run with Docker Compose
```bash
docker-compose up --build
```

### Run Lab Exercises
```bash
cd code-lab1
# Follow lab instructions inside
```
